# BOMB GAMING｜蹦蹦教學原型工程交付

## 開啟方式

解壓縮後用瀏覽器開啟 index.html，無須安裝套件或登入。圖片及蹦蹦素材已內嵌，HTML 可獨立開啟。assets/screens 保留來源影格，供工程師核對。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| index.html | 完整可操作 HTML 原型，含 CSS、JavaScript 與內嵌圖片 |
| ENGINEER_SPEC.md | 最新互動需求、正式系統整合方式與驗收条件 |

| assets/screens/ | 錄影截取畫面，未包含原始 MP4 |

## 現況與最新要求

已實作：開場是否召喚、隨時關閉／Esc、逐步框線、自動氣泡、點框前進、閱讀步驟繼續、補充說明、語音開關、角色原地輕微上下飄動。最新影片補齊佔用／重新入座／保留／倒數／已逾時。

**待實作、已確認的互動：框出目標 → 蹦蹦從上一位置飛到目標旁 → 停穩後出現氣泡 → 玩家完成該操作 → 飛往下一個目標。**
現有 HTML 仍是原地飄動及直接定位，沒有這段跨目標飛行；不可將現有動作當成最終效果。工程師以 ENGINEER_SPEC.md 的最新要求為準。

這是錄影畫面的操作原型，點框只推進教學，不會執行真實登入、遊戲、保留、兌換或結算。正式系統必須依真正的操作結果推進。

提案定位：BOMB GAMING 正式上架後，作為另外優化或升級版本上線。
